## 💜 URL Emoji Vault

A little Windows app I made to save and organise emoji URLs locally, so they're easier to find and use in apps like Discord.

**Features include:**
- 📚 Personal emoji library
- 🔎 Search, favourites and categories
- 🪟 Compact picker with system tray integration
- ⌨️ Global hotkeys for pasting emoji URLs
- 🎨 Custom themes and picker opacity
- 📤 Import and export your collection

### Links

- 💻 **GitHub:** https://github.com/VioletCaulfield/URL-Emoji-Vault
- 📥 **Downloads:** [Latest release](https://github.com/viviviolet106/URL-Emoji-Vault)

## 🏛️ Civilization Classics Collection

A preservation project dedicated to making the classic Civilization games easier to install, play and mod on modern versions of Windows.

**Features include:**
- 🖥️ Custom launcher
- 📦 Integrated installer
- 🎮 Mod Manager
- 📝 Metadata editor
- 🖼️ Preview images
- 🔄 Auto-updater
- 👥 Foundations for future multiplayer features
- 🛠️ Ongoing compatibility improvements

# 🎯 Philosophy

> Learn by building.

I believe the best way to learn programming is by creating real software, making mistakes, debugging problems, and understanding *why* things work instead of simply copying solutions.

You don't have to know everything before you start. Sometimes the best way to learn is to build something, break it, fix it, and keep going.
